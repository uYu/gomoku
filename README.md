# 五子之间 · Gomoku Atelier

参考同级 otello 的米白、墨绿棋室风格，实现的完整五子棋游戏。
React + TypeScript 界面，C++17 Rapfi 搜索与 NNUE，通过 WebAssembly Worker
在浏览器本地对弈，也可编译成原生引擎。

## 启动

需要 Node.js 22.13+：

```sh
npm ci
npm run dev
# http://127.0.0.1:5178/
```

普通网页构建使用已保存的 Wasm，无需 C++ 编译器、训练环境或外部 AI 服务。
棋盘首次加载约 37KB 的禁手 Wasm，AI 请求再按需加载约 40MB 模型与引擎。

## 玩法

- 默认连珠：黑棋三三、四四、长连禁手，恰好五连优先判胜；白棋五连及以上胜。
- 禁手点显示 ×，黑棋落下后保留棋子并立即判负；递归判断假活三。
- NNUE、实验训练模型、人机、同屏、观战和提示使用一致的禁手规则。
- 休闲无禁手模式使用官方 Freestyle NNUE，默认入门难度；双方五连及以上胜。
- 旧版恰好五连棋谱保留兼容。
- 15×15 棋盘，三档难度，选择执子、悔棋、提示、手数、音效、键盘与手机布局。
- 自动保存、JSON 导入导出、逐手与自动回放；导入会完整重放校验。
- AI 可取消，连续请求复用权重和置换表；入门落子至少等待 600ms。
- 终局保留棋盘，标明最后落子、获胜连线或禁手棋形；结果卡片突出胜负原因并可回看上一手。

采用自由落子开局，未实现交换开局等完整赛事流程。只保存当前一局，新局会替换
自动存档，请导出重要棋谱。双人同屏不含网络联机；需要 HTTP 服务，不能双击 HTML。

## AI 与棋谱

自建引擎与训练研究已按用户要求暂缓，游戏继续使用官方 Rapfi 和各规则的专用权重。
选择无禁手会默认使用官方 Freestyle NNUE 与入门难度，可自行选择熟练或进阶。
入门采用引擎最低棋力、主搜索 1 层、40ms / 256 节点预算；仍会成五和挡四，
并保留引擎战术检查。熟练采用上游 STRENGTH=20、最多 600ms，进阶采用
STRENGTH=95、最多 2200ms，启用上游候选随机选招和深度限制；提示使用
满强度 100。这是试玩分档，不对应棋力百分比或经过标定的人类等级。

本地自训模型试玩：在开发页面 URL 后加 `?trial=freestyle`。有禁手入门使用此前
从零训练的连珠黑白模型；无禁手入门使用 500 步自由规则自训模型。两者均为零
搜索，保留直接成五/堵四规则。AI 会避开禁手；人类黑棋落下三三、四四或长连
禁手即判负，棋子保留，终局原因可保存、回看和悔棋。黑棋恰好五连胜，白棋五连
或长连胜。此试玩页复用本地原生 C++
推理，通过 Vite 的本机接口调用；需已有 `.build` 实验权重和原生引擎，不能作为
纯静态网页独立运行。普通 URL、熟练/进阶与提示仍使用官方浏览器引擎。
以下实验保留为历史记录。

默认使用官方预训练 Rapfi NNUE。另从公开 WinePy 数据筛出 339 局完全符合连珠禁手
的棋谱，实际微调 1,634 个经典排序参数 400 轮，独立测试策略损失下降约 11.33%。
这不是重新训练 NNUE，也不证明棋力提升。当前连珠对照仅 4 局、2 胜 2 负，
**尚未证明超过 Rapfi**，推荐模型仍为 NNUE。

已下载并逐手审查 Gomocup 2025/2026 的 5,448 局连珠记录，作为后续个人研究数据。
来源、质量和分组注意事项见 [棋谱调查](docs/DATA_SOURCES.md)，
算法、训练与对战复现见 [引擎说明](docs/ENGINE.md)。

另有按用户要求从随机权重训练的完整 Mix9svq 实验，黑白模型分别训练，随后比较
α–β 与 MCTS。首轮仅替换模型的官方 AB 对照：100ms 为 2胜14负，500ms 为 1胜7负。
实验数据、权重和报告仅保留本地，详见
[从零训练说明](docs/NNUE_FROM_SCRATCH.md)。网页推荐模型保持原状。
